# Representative frontend fixtures

Fixtures are intercepted browser inputs or disposable test-system reads. They are not production records, proof of backend calculations, or guarantees that separately supplied aggregates are internally consistent. Report source hashes and dates determine freshness; this register does not upgrade historical results to current passes.

| Condition | Concrete fixture and assertion location | Practical limit |
| --- | --- | --- |
| Long identities and missing profile fields | `frontend/tests/premium-profile-identity.browser.mjs`: long unbroken surname; null unit/notes/end date; zero, false and empty string; current, future, past and boundary-date designation histories | Module GET fixtures. Other nullable fields and real persistence remain separate. |
| Cross-month leave and many approval rows | `premium-monthly-leave-review.browser.mjs`: 18 requests, two affected duties, October 29–December 3 range, independent duty acknowledgement and final confirmation | All preview/approval POSTs intercepted. Counts and permissions are not backend certification. |
| Large returned group list and mixed leave statuses | `premium-leave-pressure.browser.mjs`: 12 unit groups, six call groups, nine days and Approved/Requested/Imported, Pending Review; exact server counts and top-seven ordering | Pressure and calendar are independent fixtures; tests do not certify aggregate consistency. |
| Boundary collection sizes | `premium-staffing-review.browser.mjs`: 0, 1, 100 and 103 returned safety rows; final warning reachable, exact unit/month, null unit, failed read and explicit retry | Does not establish performance for arbitrarily large arrays or real staffing decisions. |
| Pending work, unknown totals and unfamiliar statuses | `premium-generation-state.browser.mjs`: eight statuses, zero-total queued job, exact positive progress, escaped server error/fallback and unknown raw state | Some terminal/unfamiliar states use defensive create responses rather than normal server transitions. |
| Explicit forced template allocation | `premium-template-forced.browser.mjs`: true, false and missing forced flag, long HTML-like unit/reason text, exact intercepted revision-27 apply | No real GPU, eligibility or assignment calculation. |
| Query with zero matches and shown-row selection | `premium-search-selection.browser.mjs`: two-choice lists, combined active/archived unit filtering, empty collection versus failed read; three shown past duties with truncation, mixed checkbox and month reset | Live-region DOM checks, not actual screen-reader speech timing or all catalog kinds. |
| Time-zone and missing timestamp boundaries | `premium-rules-history-time.browser.mjs`: Asia/Kolkata and America/Los_Angeles, offset day boundary, unzoned/missing/invalid timestamps, unchanged version/revision restore request | Audit instants only; effective policy calendar dates are deliberately separate. |
| Reviewed import lifetime | `premium-member-csv-lifetime.browser.mjs`, `premium-import-candidate-choice.browser.mjs`: old file results, held preview/apply, candidate corrections, server refusal and explicit retry | Intercepted import payloads; report freshness must be checked after module edits. No workbook/database equivalence claim. |

Every fixture family needs both normal and error/recovery outcomes where applicable. Large text overrides, reduced motion, light/dark themes and 320/1280 widths are additional test dimensions, not substitutes for physical devices or native assistive technology. The current 18-route matrix adds four-width page coverage; it does not open every modal or execute every action.
