# Rejected layout prototype

`prototype.json`, its captures and `rejected-prototype-source.mjs.txt` record an
injected CSS experiment. It was rejected after visual review: narrowing the name,
search and sort fields reduced useful text space, and the768px layout became
taller. It was not added to the application stylesheet. The executable prototype
was removed from frontend tests and retained here as diagnostic source.

The shipped implementation uses the native creation disclosure documented in
`../qa-member-create-disclosure/README.md`. Prototype results do not certify the
shipped implementation.
